# KR1

Программа для определения точки пересечения луча и треугольника,
для того чтобы найти такую точку пересечения, нужно указать 
координаты точек треугольника, координаты точки начала луча,
горизонтальный и вертикальный углы луча.

Программа поддерживает сохранение данных в файл и загрузку данных из файла
